# 高Beta短线选股策略 · 需求文档

> 版本 v1.2（2026-09-28 维护） · 状态：假设与开放问题已由 E0-E17 实验裁决（§5 逐条标注）
> 本文档基于用户原始需求整理。

## 1. 背景与目标

用户有一套「高Beta短线策略」的选股直觉，希望用 [vectorbt](https://github.com/polakowo/vectorbt) 做系统化验证。核心想法：

- **标的池**来自三个同花顺概念/风格指数（成交活跃、Beta 高、近期强势的股票天然集中在这里）；
- 用 **T-1 日及之前的 3/5/10 日量价信息** 做初筛排序；
- 用 **当日 9:35 之前（开盘后前 5 分钟）的 1 分钟实时数据** 做盘中确认；
- 9:35 之后快速确定**当日可交易标的**并入场。

### 项目目标（按优先级）

| # | 目标 | 验收标准 |
|---|------|---------|
| G1 | 打通数据管道 | 给定任意日期，能自动取到三池成分 + 所有个股日线/分钟线，落盘缓存 |
| G2 | 因子有效性初筛 | 对 3/5/10 日量价因子与 9:35 盘中因子，给出 IC / 分组收益等横截面证据 |
| G3 | 策略级回测 | vectorbt 跑通「T 日 9:35 入场 → 次日出场」的 Top-N 等权组合，含交易成本，输出净值/回撤/胜率等 |
| G4 | 当日实盘辅助 | 提供一个「早盘 9:35 运行、输出当日候选清单」的脚本（现阶段输出为研究信号，非交易指令） |

### 非目标（本期不做）

- 实盘下单对接、仓位风控（止损线、单票上限之外的约束）；
- 分钟级全量历史回测（受数据源限制，见 §4）；
- 择时/大盘择时模块（列入 v2 方向）；
- 参数寻优自动化（本期只做少量人工设定的敏感性对照，避免过拟合）。

## 2. 标的池定义

| 池 | 指数代码 | 规模（实测 2026-09-25） | 含义 |
|----|---------|----------------------|------|
| 同花顺热股 | 883910.TI | 50 | 市场关注度最高的热股 |
| 高贝塔值 | 883926.TI | 100 | 相对大盘 Beta 最高的股票 |
| 近期强势 | 883409.TI | 158 | 近期涨幅/强度靠前的股票 |

- 每日候选集 = 三池**并集去重**（预计 150~250 只）。
- 成分清单通过 iFinD `data_pool` 接口（reportname=p03473）按日获取，实测**可回溯至 2024-01-01**，每个查询日返回当日快照（point-in-time，无幸存者偏差）。

### ⚠️ 时点口径（本项目最重要的一条纪律）

三个池均为**收盘后按当日数据计算**的风格/热度排名。因此：

- **禁止**用 T 日池子在 T 日入场（前视偏差）；
- 正确链路：`T-1 日池子` + `T-1 日收盘可算的 3/5/10 日量价因子` → 初筛 → `T 日 9:35 前分钟数据` 确认 → `T 日 9:35 后` 入场。

## 3. 核心业务流程

> **[交互式交易流程图](../../reports/diagrams/workflow_trading.html)** · T-1 池快照 → 特征 → G2 门控 → 打分 → Top5 → 三批执行 → T+2 出场，含空仓分支

```
每个交易日 T（早盘）：
 1. 取 T-1 日三池成分 → 并集去重 → 候选集 U(T)
 2. 对 U(T) 内每只股票，用截至今日 T-1 收盘的日线计算因子：
      ret_3d / ret_5d / ret_10d（动量）
      vol_ratio_5_20（5日均量 / 20日均量）
      turnover_5d（5日均换手）
      amt_5d（5日均成交额，流动性过滤用）
      vol_10d（10日收益波动）
      dist_high_20（收盘价距20日高点）
      limit_up_cnt_10（10日内涨停次数）
 3. 排序取初筛名单（如 Top 30）
 4. 9:35 时点，用开盘后前 5 根 1 分钟 K 线计算确认因子：
      gap（隔夜缺口 = 今开 / 昨收 - 1）
      r_5m（首5分钟收益 = 9:35价 / 今开 - 1）
      vr_5m（首5分钟量 / 昨日每分钟均量）
 5. 确认过滤 + 打分 → 当日 Top-N（默认 N=3~5）
 6. 入场（回测近似为开盘价/9:35价 + 滑点）
 7. 出场：T+1 开盘（默认，兼容 A 股 T+1 制度）
```

## 4. 数据源与已验证边界（2026-09-27 实测）

| 数据 | 来源 | 实测结论 |
|------|------|---------|
| 三池成分 | iFinD `quantapi.51ifind.com/api/v1/data_pool`（p03473） | ✅ 任意历史日期可查，最早至少到 2024-01-01；返回 日期/代码/名称；201 交易日快照已落盘 |
| 日线 OHLCV | **本地 qlib 仓** `~/.qlib/qlib_data/cn_data`（主源） | ✅ 覆盖至 2026-09-24；前复权=raw/factor，收盘价与同花顺核对一致；无换手率字段（to_5d 因子暂缺，amt 由 volume×vwap 得出，误差<1e-6） |
| 1 分钟 K 线 | **本地 qlib 仓** `cn_data_1min`（唯一源） | ✅ 2023-12~2026-09-23 全覆盖；实盘需 qlib 仓当日更新 |
| 沪深300 基准 | qlib 仓（SH000300） | ✅ 260 行 |

**推论**：
- 主回测（E2）用日线开盘近似 9:35 入场，偏差已由 E3 在 175 日窗口量化校准（中位 0，均值 +22bps）；
- 9:35 盘中环节（E3）用本地 1 分钟仓做**全窗口精确回测**，不受东财 5 日限制；
- 当日实时选股（G4）优先东财实时分钟，失败自动回退本地 qlib 仓（需当日已更新）。

## 5. 假设与开放问题（v1.2 已逐条裁决）

| # | 假设（v0.1 采用） | 裁决结果（实验依据） |
|---|----------------|-------------------|
| A1 | 出场规则 = 次日开盘卖出 | ❌ 已推翻。E7 三档对照：T+1 开盘卖最差，**T+2 收盘卖 + 三批次资金**最优（E12 双周期确认） |
| A2 | Top-N 等权，N=3~5 | ✅ 保留 N=5 为基线；E17 敏感性：**N=3 双周期均更优**（激进档），N≥8 在 24-25 转负 |
| A3 | 成本 = 往返 0.55% | ✅ 保留；E17：滑点加到 0.3% 两期仍 +26%/+39% |
| A4 | 涨停可交易性粗近似 | ⚠️ 部分保留。gap>7% 一字剔除保留；E10 发现模型经交互特征已隐式规避高潮期高位板。竞价数据细化仍未做（已知未决） |
| A5 | 回测窗口 2026-01~09 | ✅ 已扩展。E12 跨周期复检：2024-01~2025-12 独立验证通过 |
| A6 | 前复权 | ✅ 保留（与同花顺收盘价核对一致） |

**开放问题裁决**：
- Q1（N 与流动性过滤）→ E17 解决：N=5 基线 / N=3 激进档；5 日均成交额 ≥1 亿过滤保留。
- Q2（一字板精细度）→ 部分解决：E10 相位交互隐式规避 + gap>7% 显式剔除；竞价级细化列入已知未决。
- Q3（三池等权 or 热股优先）→ E5/E12 解决：**分池强弱周期翻转**（高贝塔 24-25 最强/26 最弱），并集为跨周期稳健选择；多池加成未采纳。
- Q4（立即入场 or 回踩）→ E3/E4 解决：不做确认过滤，9:35 特征直接入联合模型打分（两段式确认被 E3 推翻）。
