# 组合层验证结论（E45）

> 把 E44 胜出因子推进到可交易口径：统一 14:45 入场轨（T-1 日频因子 + T 日 14:45
> 分钟因子）、池内前 20% 等权、封板 REPLACE、成本往返 0.55%/段，毛/净双口径，
> 2024-01-02~2026-09-24（662 天）。出场变体 V1=次日 9:35 卖（隔夜段）、
> V2=次日 14:45 卖（隔日合计）。实验登记 v1.12 / E45。

## 一、四层可成交性审计（本轮方法论核心）

E45 初版结果因数据口径问题严重失真，逐层修复并固化如下纪律：

| 层 | 问题 | 修复 | 影响 |
|---|---|---|---|
| ① 昨收基准 | `c.shift(1)` + 日期映射双重 shift，封板判定用 T-2 收盘 | 基准改 `c`（映射已含 T-1 取值） | 持仓结构纠正 |
| ② 封板 | 14:45 已涨停票不可买 | `p1445/昨收−1 ≥ 板块涨停幅−0.1%` 剔除顺延 | 已有 |
| ③ 准一字 | 日内高低差 <1% 的横盘票 14:45 无有效对手盘，其"纸面反弹"污染分组（占持仓 8.2%、贡献约三分之一表观收益，h_1d 均值 +6.95%/次） | `hi_sofar/lo_sofar−1 ≥ 1%` 剔除 | 表观收益削减 |
| ④ 流动性 | 低成交额票冲击成本失真 | 截至 14:45 成交额 ≥3000 万元 | 影响甚微（持仓本就活跃） |

审计还发现 pull_hi 的海量精确平局（p1445=hi_sofar，值=0）使 nlargest 退化为
代码序伪选择、rank 平均化稀释 E44 多空——E44/E43 的 hi 组口径实际是"全体平局票"，
**多空数字与组合数字的口径差异由此而来**。

## 二、验证结果（净口径，年化/最大回撤）

| 组合 | V1（次日 9:35 卖） | V2（次日 14:45 卖） |
|---|---|---|
| **pull_hi·G2 门控** | +693% / −11.2% | **+2303% / −11.8%** |
| **pull_hi** | +312% / −17.5% | **+971% / −23.7%** |
| pos_lowamp | +39% / −23.6% | +103% / −36.8% |
| 跨频复合 x_freq | −90% / −99.8% | −97% / −100% |
| 纯日频对照 | −95% / −100% | −99% / −100% |
| 池基准（零换手毛口径） | ≈−94%/年 | ≈−91%/年 |

三条硬结论：

1. **pull_hi（14:45 贴日内高点）组合在四层审计后仍大幅为正**：V2 净年化 +971%、
   回撤 −24%；月度分布广泛（33 个月 29 正、88% 正月率、最大三月仅占总量 37%，
   除 2024-09 政策月 +114% 外常态 +10~50%/月）——**不是单一事件驱动**；
2. **G2 情绪门控是强放大器**：pull_hi·V2 从 +971% → +2303%、回撤 −24% → −12%
   （门控剔除深跌期交易，v1.5 组件在 14:45 轨的独立再现）；
3. **跨频复合失败、日频因子与 14:45 入场不兼容**：x_freq/daily_score 全线
   −84%~−100%——日频反转/缩量因子在 14:45 买入是"接飞刀"（E43 已示隔夜段是
   风险释放段）。日频信息的正确用法是回到 9:35 入场轨或作**池筛选**而非打分。

## 三、保留怀疑清单（如实声明，数字的可实盘性边界）

1. **滑点假设**：0.2% 滑点对"尾盘追贴高点票"可能低估（政策日尤甚），未做
   冲击成本敏感性；
2. **跌停无法卖出**：V1/V2 的卖出时刻若持仓票跌停则实际卖不出，回测按可卖计
   ——低估左尾损失，待补"跌停顺延卖出"变体；
3. **V1/V2 差异与 E43 分解的表面冲突**：E43 多空口径显示次日日内段贡献≈0，
   而组合层 V2 比 V1 强 3 倍——源于平局口径差异（见 §一），待统一口径后复核；
4. p1445 为分钟 bar 收盘价，与实际可成交价的微观差异未建模。

**结论定位**：+971%/+2303% 是"四层审计后、两处待复核前"的研究口径数字，
方向与量级排序可信（pull_hi ≫ pos_lowamp ≫ 日频轨组合），绝对水平在怀疑清单
闭环前不应作为实盘预期。

## 四、裁决与下一步

- **P0 因子面的组合层排序**：pull_hi（核心）＞ pos_lowamp（温和）；
  日频因子出局 14:45 轨（回 9:35 轨或作池筛选）；
- 下一步优先级：①怀疑清单闭环（跌停卖出变体 + 滑点敏感性）；②pull_hi 的
  持仓结构刻画（深跌企稳 vs 强势延续两类子结构的分解与分别验证）；③
  9:35 轨的对应验证（pull_hi 逻辑在开盘轨是否有对应物：gap+首 5 分钟）。

## 五、补遗：分年稳健性与两个解释（E45 审计补充）

1. **分年超额（毛口径，pull_hi·V2 对同过滤池基准）**：2024 年 +254 / 2025 年
   +208 / 2026 年 +141 bps/日，日超额中位 +179bps、胜率 87.3%；剔除
   2024-09-20~10-10 政策事件窗后仍 +205bps/日——与 §二 的月度分布证据互为
   独立确认，超额跨年稳定且逐年温和衰减（衰减本身提示拥挤/容量约束，跟踪项）；
2. **V2>V1 的另一种解释（与 §三.3 互补）**：E43 的段分解是多空口径（空头端在
   隔夜段崩，拉高多空的隔夜占比），**多头组**的次日日内段为正（高开后继续
   走强）——多头的收益段分布 ≠ 多空的收益段分布，14:45 轨的出场结构必须按
   多头口径单独设计，不能从多空分解外推；
3. **跨频复合的重构方向**：x_freq 失败的根因是日频**超跌**打分与 14:45 买
   结构性互斥；日频信息在 14:45 轨的正确形态是**质量/缩量类筛选**（不依赖
   买入时点规避风险段）——下轮按"日频缩量质量筛池 × 分钟 pull_hi 择时"重构。
