## 指标口径速查（分册表格数字的读法）

分册与 `exp39_factor_metrics.csv` 中的列含义统一在此解释，两个最常被误读的列加粗：

- **IC（ic1_mean）**：因子值与次日前瞻收益的逐日截面 Spearman 秩相关均值。
  **正负号是方向信息**：负 IC = 因子值越高次日越差，反号使用即可（分册表格一律保留原方向）。
- **t 值（ic1_t）**：IC 均值的显著性统计量，|t|>2 视为显著。
- **Q1/Q5 年化（q1_ann/q5_ann）**：每日按池内因子值分 5 组（Q1=最低 20%、Q5=最高 20%）、
  组内等权持有 fwd1（T 开盘→T+1 开盘）的日均收益 × 244。
- **多空年化（ls_ann）**：Q5 年化 − Q1 年化。它衡量的是**因子区分度的大小**，不是
  可交易的绝对收益——本池 2024-2026 整体深跌，两组年化同时为负是常态，负号只说明
  "低值组相对更好"（即因子应反向使用），绝对值才是强度。
- **自相关（autocorr）**：因子当日截面排名与前一日截面排名的相关均值，即**换手特性**——
  接近 1 表示因子值日复一日几乎不变（排名稳定，据此调仓换手低、成本钝感）；
  接近 0 表示排名每天大洗牌（换手高，高换手因子在 0.55% 往返成本下衰减更快）。
  经验读法（本仓五库实测范围 0.01~0.98）：≥0.85 视为低换手，≤0.4 视为高换手。
- **覆盖度（coverage）**：池内非缺失样本占比（低覆盖常见于长回看窗口与深层嵌套公式）。

## 三大主线速览（五库收敛的共同信号）

| 主线 | 代表因子（库·名称） | 池内方向 | 与项目既有结论的对应 |
|---|---|---|---|
| 中期缩量 | Alpha360·VOLUME46~59、Alpha158·VSUMN 族 | 量越缩越好（IC 约 +0.06） | vr_5_20 短窗量比向 60 日窗延伸 |
| 低位反转 | Alpha158·MIN10、Alpha360·LOW6~8、华泰·HT_REV_5 | 价格贴近区间低点越好（多空最高 +162%） | v0.1 时代 ret_5d 负向（追涨杀跌失效） |
| 波动收敛 | Alpha158·KLEN、国君·G158、华泰·HT_VOL_20 | 振幅/带宽越大越差（IC 约 −0.066） | amp_5d / amp_sofar 负向 |

多空收益几乎全部来自空头端（Top 因子 Q1 年化 −100%~−154% vs Q5 −0.6%~+12%，
毛收益口径）——因子价值主要是**避开最差的票**，与 E24"空头端识别力"一致；
且五库 |IC(fwd3)|/|IC(fwd1)| 中位一致为 1.75~1.89，信号 3 日兑现优于隔日。
