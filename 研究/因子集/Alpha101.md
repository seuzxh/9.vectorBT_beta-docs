# Alpha101（WorldQuant 公式因子集，101 个）

> 来源：Zura Kakushadze, *"101 Formulaic Alphas"*, 2015（arXiv:1601.00991）。
> 本仓实现：`src/factor_libs/alpha101.py`（99 个通过样本量门槛，A096/A097
> 因嵌套过深池内样本不足自动剔除）。

## 1. 因子构成归类

与 Alpha158/360 的"族×窗口"结构不同，Alpha101 是 **101 条独立公式**，但按
构造语法可归四类：

| 构造语法 | 数量（约） | 代表 | 特点 |
|---|---|---|---|
| 截面 rank 组合 | ~45 | #5、#12、#41 | rank(rank(x)·rank(y)) 式嵌套，横截面稳健化 |
| 时序相关/协方差 | ~30 | #2、#6、#26 | corr(rank(x), rank(y), n) 量价背离类 |
| 条件状态切换 | ~15 | #7、#9、#21、#46 | 三元条件制造"放量/趋势/带突破"状态分支 |
| 长窗衰减复合 | ~11 | #71、#84、#94 | adv 均量 + decay_linear + ts_rank 深层嵌套 |

## 2. 特点

1. **算子语法化**：全部公式由少数算子（rank/ts_rank/corr/decay_linear/条件式）
   组合而成，学的是"因子构造语法"而非经济含义；
2. **横截面 rank 泛滥**：101 条几乎条条含 rank——为对离群值稳健、为跨股票可比，
   但也导致因子值分布高度压缩；
3. **美股基因**：原为美股日频短线因子（2015 年前后），adv20/adv60 等均量窗、
   gap 类结构都针对美股微观结构调过；
4. **换手最高**：池内因子自相关中位仅 0.608（五库最低），条件切换 +
   rank 幂次使因子值日度抖动大。

## 3. 应用场景

- **原设计场景**：美股全市场日频短线 alpha 挖掘的"公式库"，供人工筛选与
  遗传规划等自动搜索算子的种子；
- **本项目场景**：只适合**择优吸收个别构造**（量价背离类），整库移植已证伪
  ——见下节。它是"跨市场移植必须重检"的反面教材，也是方法论教学素材。

## 4. 本仓实测特性（E39，663 交易日，三池并集）

| 指标 | Alpha101 | 五库排名 |
|---|---|---|
| \|IC\| 中位 | 0.013 | 第 5（最弱） |
| \|ICIR\| 中位 | 0.117 | 第 5 |
| \|t\|>2 因子数 | 66/99 | — |
| 因子自相关中位 | 0.608 | 第 5（换手最高） |

Top 因子（池内仍可用）：

| 因子 | 公式要点 | IC | t | 多空年化（毛） |
|---|---|---|---|---|
| A006 | −corr(open, volume, 10)：开盘价与量的 10 日负相关 | +0.045 | +8.9 | +82% |
| A040 | −rank(std(high,10))·corr(high,vol,10)：高波动×量价相关 | +0.040 | +8.4 | +64% |
| A088 | min(rank 链, ts_rank 链) 复合 | +0.052 | +6.9 | +63% |

衰减原因（可归因三点）：①18 个行业中性化因子在无行业数据时退化为截面去均值
（偏离清单见 05 文档 §4）；②美股微观结构（adv 窗口、gap 行为）与 A 股涨停/
T+1 制度不匹配；③研究对象是"高波动三池"而非全市场——rank 语法在极端截面
上的分辨力被池内同质化稀释。

## 5. 代表因子示例

```python
from factor_libs import compute_library
for name, panel in compute_library("alpha101", w):
    if name == "A006":        # -1 * correlation(open, volume, 10)
        pv_div = panel        # 开盘价与成交量 10 日负相关：池内最强 Alpha101 因子
```

| 因子 | 原公式 | 池内表现 |
|---|---|---|
| A006 | −corr(open, volume, 10) | IC +0.045：开盘价高但量缩（价升量缩背离）→ 好 |
| A101 | (close−open)/((high−low)+0.001) | 简单日内强弱，池内 IC 弱——越简单越接近 Alpha158 的 KMID |
| A096/A097 | 深层嵌套（adv81/ind 类退化） | 池内样本不足剔除——嵌套越深、可用样本越少 |

## 6. 使用建议

- 不建议整库并入模型；仅 **A006（开盘量价背离）** 值得与基线 vr_5_20 之外的
  量价因子一起做 walk-forward 复检；
- 若引入行业数据（如申万一级），优先重算 18 个行业中性化因子的**未退化版本**
  再下结论——当前结论只对"退化版"负责；
- 教学价值大于实用价值：它示范了 rank/条件/decay 三类算子的全部组合形态，
  是自研因子时的公式模板库。
