# 国君191（国泰君安短周期价量因子集，191 个，本仓 187 个）

> 来源：国泰君安证券金融工程（刘富兵团队）《基于短周期价量特征的多因子选股
> 体系》（2017-06）。业内常经聚宽（JoinQuant）社区与因子库移植，故也俗称
> "国君聚宽因子"。本仓对照 popbo/alphas（全量 pandas 版）与 aurumq-rl
> （算子语义批注）转写：`src/factor_libs/gtja191.py`。
> 跳过 4 个：#30（需 MKT/SMB/HML 三因子回归）、#143（SELF 引用）、
> #149（FILTER 条件回归语义不明）、#190（嵌套 SUMIF 转写歧义）。

## 2. 特点

1. **唯一原生 A 股体系**：2017 年直接在 A 股全市场调参成文，短周期（1~20 日）
   定位与本项目三池短线完全同频；
2. **中式算子**：SMA(X,N,M) 递推平滑（等价 ewm(alpha=M/N)）、WMA 线性加权、
   REGBETA 滚动回归——与通达信/同花顺指标语言同源，技术指标部分可直接对照
   主流看盘软件语义；
3. **条件求和/计数是灵魂**：涨日量与跌日量分开累计（#40/43/84）、高低点
   抬升波幅分档（#49/55/137）——刻画"上涨日的行为特征"这一 A 股特有结构；
4. 公式里大量出现 `-1 ×` 与镜像对（#23/#160、#53 等），同族因子方向相反。

## 3. 应用场景

- **原设计场景**：A 股全市场短周期多因子选股（研报原始组合为周频调仓）；
- **本项目场景**：与三池短线结构**天然同频**，分族择优即可用——其摆动/乖离/
  波宽带族在池内 147/187 个 |t|>2；亦适合作为"看盘指标语义"的因子化模板
  （KDJ/RSI/CCI/ARBR 都在这套里）。

## 4. 本仓实测特性（E39，663 交易日，三池并集）

| 指标 | 国君191 |
|---|---|
| \|IC\| 中位 / \|ICIR\| 中位 | 0.023 / 0.176 |
| IC>0 占比 | 46%（动量/乖离类负 IC 居多，取反即正向） |
| 因子自相关中位 | 0.830（换手中等偏低） |

Top 因子（按 |ICIR|）：

| 因子 | 语义 | IC | t | 多空年化（毛） |
|---|---|---|---|---|
| G158 | 布林带宽：(high−SMA15)−(low−SMA15) 再除以 close | −0.065 | −11.8 | −79%（带宽扩张→差） |
| G020 | 6 日涨幅×100 | −0.064 | −10.8 | −159%（短线涨幅→次日差） |
| G031/G066/G071 | 12/6/24 日乖离率 BIAS | −0.062~−0.066 | ≈−10 | −135%~−149% |
| G034 | Mean(c,6)/c（G031 的倒数镜像） | +0.062 | +10.3 | +152% |

镜像结构清晰：**同一信息（乖离/带宽/短线涨幅）在库内成对出现，方向相反**，
IC 分布因此 46% vs 54% 近乎对称。解读时应把"负 IC 的动量因子"读作
"反向使用的反转因子"。

## 5. 代表因子示例

```python
from factor_libs import compute_library
for name, panel in compute_library("gtja191", w):
    if name == "G040":     # 涨日量和 / 跌日量和 × 100
        vol_bias = panel   # >100 表示上涨日放量占优
```

| 因子 | 公式（研报语义） | 池内方向与解读 |
|---|---|---|
| G040 | SUM(涨日量,26)/SUM(跌日量,26)×100 | 涨日量占优 → 次日偏差（量能透支，需反号用） |
| G075 | 基准下跌日中个股上涨的天数占比 | 逆势 strength：池内中等正向 |
| G163 | −RET×均量×VWAP×(high−close)（华泰也收录同构） | 与 HT 系同源的反转复合 |
| G028 | 3·SMA(KDJ_K)−2·SMA(SMA(KDJ_K))（KDJ 的 J 线） | 经典摆动，池内弱于其带宽/乖离同门 |

**口径提醒**：本仓 #62 采用主流开源转写的 volume 口径（aurumq 以
amount/cap 代理换手率属少数派）；#59/#84 修正了 popbo 转写笔误；
SMA 全部按 ewm(alpha=M/N) 递推实现（与通达信一致）。

## 6. 使用建议

- 优先吸收 **G158（波动收敛）与 G034/G031 族（乖离反转）**——与基线
  ret_5d/amp 同主线但角度不同（带宽 vs 振幅、乖离 vs 动量），相关性待复检后
  决定是否并列入模；
- 条件量能族（G040/G043/G084）是本项目现有因子面没有的"涨跌日行为分解"结构，
  值得单独做一轮池内 walk-forward；
- 镜像因子只取一侧，避免共线膨胀。
