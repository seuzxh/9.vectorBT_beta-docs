# 华泰经典因子库·价量子集（28 个 / 全库约 70 个）

> 来源体系：华泰金融工程《华泰多因子模型体系初探》（多因子系列之一，
> 2016-09-21）与《华泰人工智能系列之七：人工智能选股之 Python 实战》
> （2017-09-12，附约 70 个因子的清单）。
> 数据边界：全库含估值/成长/财务质量/杠杆等需财务数据的大类，本仓日线仓
> 无财务字段，故只按其大类框架自建价量子集 28 个：
> `src/factor_libs/huatai.py`。**这不是研报原表复刻，而是其框架的价量投影**
> ——引用时须注明。

## 2. 特点

1. **风格因子分类学**：华泰体系的最大价值是 Barra 式大类框架——它提醒
   IC 之外还要看因子属性（波动率/流动性类通常是**风险补偿**而非 alpha，
   有效也不宜单因子重仓）；
2. **月频/周频基因**：原框架定位中低频选股，窗口偏长（20/60/120 日），
   自相关全场最高（0.941）——因子极稳定、换手极低，但短线灵敏度最低；
3. **技术指标口径中国化**：RSI/KDJ 用 SMA(X,N,3) 递推（同国君 191），
   MACD 用标准 EMA(12/26/9)；
4. 特异波动（IVOL）与 Beta 需要对沪深300 的滚动回归，是五库中唯一天然
   含**基准联动**结构的库。

## 3. 应用场景

- **原设计场景**：月频/周频多头选股与指数增强的风险模型输入；
- **本项目场景**：当作**风格控制与过滤因子**而非短线 alpha——池内 89% 的
  因子 IC 为负（动量/波动/超买方向），反向使用即"避开高波动、高乖离、
  高Beta 的票"，与三大主线同构；Beta_120 族与项目 v0.8 时代 beta_120
  结论直接可比。

## 5. 代表因子示例

```python
from factor_libs import compute_library
for name, panel in compute_library("huatai", w):
    if name == "HT_AMIHUD_20":   # 20 日均 |ret|/成交额（Amihud 非流动性）
        illiq = panel            # 值大 = 单位成交额撬动更大价格变动 = 流动性差
```

| 因子 | 公式要点 | 池内方向与解读 |
|---|---|---|
| HT_AMIHUD_20 | mean(\|ret\|/amount, 20) | 非流动性正向偏弱——本池股票普遍高波动，区分度有限 |
| HT_TURN_PX_20 | volume / MA20(volume)（量比，换手代理） | 负向：当日相对放量 → 次日差（同缩量主线） |
| HT_IVOL_60 | 对沪深300 回归残差的 60 日波动 | 负向 −0.045：特异波动大 → 差（风险补偿方向） |
| HT_BETA_120 | 对沪深300 的 120 日回归斜率 | 池内弱——三池本就是高Beta选出的样本，横截面上 Beta 已被预筛 |

## 6. 使用建议

- 本子集的定位是**风格坐标**：用 HT_VOL_20/HT_IVOL_60/HT_BETA_120 做持仓
  风格监控与负向过滤（避开波动/乖离极端值），而不是追求其 IC；
- HT_REV_5 与基线 ret_5d 完全同源，无需重复引入；
- 若后续接入 iFinD 财务数据，本框架可直接扩展回估值/成长大类，
  华泰全库（约 70 因子）的复现路径已在 05 文档 §2 登记。
