# 术语表

> 目的：统一项目文档用词，避免英文直译造成的歧义。2026-09-28 起生效；
> 早期文档中的「臂」「腿」等直译说法已全部替换为下表的标准说法。

## 已替换的直译词

| 标准说法 | 旧说法（直译） | 英文来源 | 含义 |
|---|---|---|---|
| **子策略 / 策略分支** | 臂 | arm（多臂老虎机/临床试验的"试验组"） | 同一框架下按条件切换的选股分支。E11 按市场阶段切换四条：动量子策略（主升）、反转子策略（震荡）、模型子策略（上涨）、空仓（下跌）。注：代码与 CSV 中列名仍为 `arm`，含义同此 |
| **确认环节 / 盘中环节** | 腿 | leg（原为期权/价差策略行话，如"双腿价差"） | 交易流程的组成环节。「9:35 确认环节」= 用开盘后前 5 根 1 分钟 K 做盘中确认的部分；「精确验证环节」= 用 1 分钟数据替代开盘价近似 |
| **标的全集** | 宇宙 | universe | 策略可选股票的整个集合（= 三池并集）。文档中也可直接说「这批标的」「池子」 |
| **反向指标** | 反指 | — | 因子值越高、未来收益越差（IC 为负）。口语「反指」不用于正式文档 |
| **批次** | （原词保留） | batch / vintage | 资金分批入场的每一批。E7-C「三批次」= 资金分三份、错日入场、各自持有至 T+2 收仓，以规避 T+1 制度下的资金占用冲突 |

## 行文缩写约定

正式表述中以下缩写可以出现，但首次使用需可从上下文读懂：

| 缩写 | 全称 | 说明 |
|---|---|---|
| 毛 / 净 | 毛收益 / 净收益 | 毛 = 不含交易成本；净 = 含佣金+印花税+滑点（往返 0.55%） |
| 中位 | 中位数 | 常用于「中位数口径 −62%」这类截面统计 |
| bps | 基点（万分之一） | 日均 +49bps = 平均每天赚 0.49% |
| pp | 百分点 | 「回撤改善 8pp」= 回撤减少 8 个百分点 |
| IC / RankIC | 秩相关信息系数 | 因子值与未来收益的当日截面秩相关；t 值衡量其显著性 |
| OOS | 样本外（out-of-sample） | 模型未参与训练的测试区间（本项目 2026-03~09） |
| T / T-1 / T+1 | 交易日序号 | T = 入场日；T-1 = 前一交易日（信号口径）；T+1 = 次一交易日 |

## 保留使用但易混淆的术语

| 术语 | 英文来源 | 含义 | 备注 |
|---|---|---|---|
| **门控** | gate | 是否开仓的交易开关。如 G2 = 涨停家数 5 日均 > 20 日均才交易 | 也叫「仓位开关」 |
| **消融** | ablation（机器学习标准译法） | 逐组增删特征、对比效果的实验方法（如 E4 的 daily/intraday/joint 三组对照） | |
| **相位**（E10） | phase | **情绪周期**所处位置：高潮 / 分歧 / 常规 | 与「阶段」严格区分 |
| **阶段**（E11） | regime | **锚指数趋势**状态：主升 / 上涨 / 下跌 / 震荡 | 记忆口诀：相位说情绪，阶段说趋势 |
| **速度切换** | —（本项目自造词，替代直译「路由/routing」） | 根据轮动速度指标在两套特征组之间切换：快轮动→短窗特征（SWAP），慢轮动→标准窗（STD）。E14 提出、E15 复检后**未被采纳**（固定短窗双周期均更优），仅保留于实验记录 | 也叫「按速度选窗」 |
| **锚指数** | anchor | 用于判定市场阶段的基准指数 = 同花顺全A（883957.TI） | |
| **净化** | purge | 训练/测试边界处剔除重叠样本日，防止未来信息渗入（本项目剔除边界 1 日） | |
| **面板** | panel | （日期 × 股票）的二维数据表，如 `e9_panel.parquet` | |
| **逐日盯市** | mark-to-market（通行译法） | 组合净值按每个交易日的收盘价逐日结算；多批出场结构的段收益须分布到其发生的交易日（seg2 记在 T+1、seg3 记在 T+2），而非全记在入场日 | E18 修正口径 `nav_fix` 的核心要求；与「入场日记账」相对 |
| **基线** | baseline | **v1.6 诚实基线**（REPLACE 可成交过滤 + 尾盘模型出场过滤 q=0.4 + v1.5 门控/止损/T+2 出场：2024-25 +22.1%/回撤 −21.8%、2026 +9.5%/−16.3%（2026-10-03 重建复验口径））。⚠️ v1.5 官方口径（+185%/+29%）的盈利几乎全部由 9:35 已封板、不可靠成交的 20% 交易承载（E25 复检），仅作对照保留 | E22 日频记账口径，逐笔全额/3 记入场日 |
| **walk-forward** | — | 滚动前推验证：按月扩张训练窗、逐月做样本外预测（本项目 OOS = 2026-03~09） | 亦可译「滚动前推验证」，文档保留英文 |
| **尾盘买入 / 尾盘决策** | end-of-day entry | 把决策与买入时刻放在 T 日 14:45（临近收盘）的入场结构，与基线 9:35 相对。E23/E24 裁决：本池长端不可行 | 也说「14:45 方向」 |
| **未来函数 / 前视** | look-ahead bias | 用决策时点之后才可获得的数据参与信号或成交计算，导致回测虚高。本项目防线：tailwin 分钟聚合只用 hhmm≤1445 的 bar；日频因子一律 T-1 收盘口径；池成分 T-1 收盘 | 代码注释中多称「防前视」 |
| **日线回退** | —（本项目自造词） | E47 出场状态机中，持仓次日在池内无分钟行（掉出 T 日池）时改用次日日线数据近似出场的路径，出场方式标注「次日卖(日线)」。v1.14 起该路径完整执行状态机（开盘价近似 9:35 止损、收盘价判涨跌停） | 也说「池外票回退」 |
| **日历净值 / 日历年化** | calendar NAV / annualized | 净值按报告窗全部交易日（含空仓日，记 0 收益）逐日结算；年化 = 终值^(244/交易日数)−1。与「按开仓日折算」（v1.14 前旧口径，把 289 个开仓日当一整年，虚大约一个数量级）相对 | |
| **末价入账** | —（本项目自造词） | 出场数据缺失时按可得最后价格×(1−0.1%) 保守记账并显式计数，禁止 skipna 静默跳过 | |
| **影子重放** | shadow replay（描述性译法） | 统计口径：计算「若应用某过滤/规则会发生的交易」的指标但不计入正式组合，用于量化该规则的影响面 | |
| **受控语言（ASD-STE100 风格）** | ASD Simplified Technical English，规范编号 ASD-STE100 | 航空维护文档的受控语言规范：受限词表、短句、一句一义、主动语态、术语零同义替换、程序用编号祈使句。本项目借用其原则输出中文评审与结论文本 | 也说「STE 风格重写」 |
| **尾盘窗口聚合** | tailwin（代码标识符） | 每 (股票, 日) 只用 ≤14:45 的 1 分钟 bar 聚合出的特征数据（关键时点价/截至高低点/分段量/VWAP/聪明钱）。与 daywin（全天聚合）相对——daywin 含 14:45 后信息，只能作 T-1 滚动史 | 落盘 `intraday_tailwin.parquet` |
| **封板不可买 / 可成交过滤** | fillability filter | 决策时刻股价已达板块涨停幅（前复权口径 ±0.1% 容差）的票从候选剔除——涨停价封死时买单排队难以成交。E24 发现未过滤时纸面 alpha 91% 来自封板票（封板组 +2.34% vs 可买组 −0.54%） | 参数 `SEAL_BUF` |
| **近板** | near-limit | 决策时刻股价距涨停幅 <0.3% 但未封死——可以买，但成本极高、当日上行空间被截断 | |
| **隔夜漂移** | overnight drift | T 收盘→T+1 开盘的收益段。本池候选等权口径均值 −51/−39 bps（2024-25/2026），是尾盘买入结构的最大亏损源 | |
| **尾盘出场过滤器** | tail exit filter | 对 9:35 基线持仓，在 T 日 14:45 用尾盘信号（模型分数日内分位 < q）决定当日提前出场（锁定 9:35→14:45 收益）还是继续持有至原出场。E26 裁决：模型版双周期有效、规则版不稳 | 信号列 `tail_model_pct` |
| **REPLACE / CASH** | —（E25 变体名） | REPLACE=9:35 封板票剔除后选次优 Top5（实盘可行口径）；CASH=封板槽位当日空仓（下界参照）。E25 裁决 REPLACE 优于 CASH | |
| **因子集 / 因子库** | factor library | 一套成体系的因子集合（E39 引入五套：Alpha158/Alpha360/Alpha101/国君191/华泰价量）。「库」指代码层面的注册表 `factor_libs` | |
| **O2O** | open-to-open | 开盘到开盘的前瞻收益口径：T 开盘买入→T+1 开盘卖出（fwd1）或 T+3 开盘卖出（fwd3）。与基线 `forward_return_open_to_open` 同构 | E39 主评估口径 |
| **ICIR** | IC information ratio | IC 均值 ÷ IC 标准差（逐日序列），衡量因子预测力的稳定性；排序时取绝对值 | |
| **因子自相关** | factor autocorrelation | 因子当日与前一日截面秩相关的均值：越高=因子值越稳定、据此调仓的换手越低。E39 用于刻画各因子集的换手特性 | |
| **行业中性化（退化）** | indneutralize (degraded) | 原义=按行业分组剔除组内均值。本地仓无行业数据，E39 对 Alpha101 的 18 个此类因子退化为当日全截面去均值 | 偏离已在 05 文档 §4 登记 |
| **量比（换手代理）** | — | 成交量 / 20 日均量，用作换手率的代理（本地仓无股本数据，无法算真换手率） | 华泰 HT_TURN_PX_20 |
| **W 式切割** | W-cut（开源证券研报术语） | 把传统因子（反转/振幅）按交易行为指标（原版=单笔成交金额）将回看期分半组、分别求和作差的增强手法。E40 裁决：在本池方向反转、不增益（信号集中于高成交额日） | E40 BEH_IDEAL_REV_20 |
| **聪明钱（2.0 口径）** | smart money | 分钟级指标 s=\|收益\|/√量 从大到小排序、成交量累积占比前 20% 的分钟视为机构交易，其 VWAP 对全日 VWAP 的偏离。与 E8 单日版（分钟数前 20%）口径不同 | E40 BEH_SMARTQ_V2_10 |
| **股价同步性** | stock synchronicity（Morck 2000） | 个股日收益对市场收益回归的 R²；1−R² 越高=走势越"特立独行"。E40 在本池为负向（随大盘同动者次日更稳） | ACAD_SYNCH_60 |
| **APM（量能近似）** | —（开源证券系因子） | 原版=隔夜与下午收益残差差；本仓以 log(上午量)−log(下午量) 近似，日内时段行为不对称 | BEH_APM_5/20 |

## 通用术语（不注）
