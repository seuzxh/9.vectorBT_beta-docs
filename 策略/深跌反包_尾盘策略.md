## 二、标的池定义

三池并集（883910 同花顺热股 / 883926 高贝塔值 / 883409 近期强势），**T-1 收盘成分**
（约 150~280 只，日中位 191）；剔除 ST/退市风险/北交所（项目 tradable_filter 惯例，
2026-10-05 P0-2 起回测链路同口径执行；ST 按最新简称，历史时点状态不可考）。
池数据源：iFinD data_pool（`fetch_pools_v2.py`），每交易日 09:00 前更新。

## 三、出场状态机（逐日按优先级执行；买入价 = 成交价含滑点）

```
D+1 09:35  收益 ≤ −4% ？ ── 是 → 市价止损卖出（结束）
D+1 14:45  跌停？（≤昨收×(1−板块幅+0.1%)）── 是 → 顺延（回到下一日 09:35 流程）
           涨停？（≥昨收×(1+板块幅−0.1%)）── 是 → 持有（回到下一日流程）
           否则 → 限价卖出（结束）
D+3 15:00  仍持有 → 收盘市价强平（结束）
停牌       顺延至复牌日，按复牌日 14:45 状态机执行
```

**池外票（不在 T 日池内的持仓，重放中约占六成笔）**：同样执行上述状态机——次日 9:35
止损检查照常（开盘价即可判定）、非涨跌停持有至 14:45 卖出、跌停（卖不出）与涨停顺延。
回测对池外票以日线近似执行同一状态机（开盘价近似 9:35 止损检查、收盘价对照涨跌停
阈值、非涨跌停按收盘×(1−0.1%) 记卖出），与实盘口径一一对应（2026-10-05 P0-3 修复）。

板块涨停幅：主板 10% / 创业板(30xxxx)与科创板(68xxxx) 20% / 北交所 30%（已剔除）。

## 四、每日操作 SOP

**盘前（09:00-09:30）**
1. 更新池成分（fetch_pools_v2）；核对门控状态（sentiment 更新至 T-1）；
2. 门控 = 关闭 → 今日无新仓位；持仓出场流程照常；
3. 检查数据链路健康（§七预案）。

**盘中（14:40-14:50）**
1. 14:40 拉取实时截面：现价、日内高低、截至成交额、尾盘 15 分量、昨收、20 日涨幅；
2. 14:43 运行 `select_1445.py`（或人工按 P5-P9 规则）；核对清单 ≤8 只；
3. 14:45-14:50 限价（=现价）分批买入；**单票偏离现价 >1% 放弃该票顺延次优**；
4. 逐笔记录：代码/成交价/量/时刻/信号值（写入交易日志，格式见 §六）。

**次日（09:30-09:40 / 14:40-14:50）**
1. 09:35 检查全部持仓止损线（P4）；
2. 14:45 按状态机执行出场；
3. 收盘后对账（§六）。

## 五、风控与熔断

| 层 | 触发 | 动作 |
|---|---|---|
| 单笔 | 次日 9:35 破 −4% | 止损（状态机） |
| 单日 | 组合单日亏损 ≥ 6% | 次日降半仓（4 只）一日 |
| 连续 | 连亏 ≥ 5 个交易日 | 降半仓直至首个盈利日恢复 |
| 月度 | 分月胜率 < 60% 或月亏 > 15% | 降半仓 + 人工复查（§八触发线） |
| 结构 | 分月胜率连续两月 < 55% | 停策复检（生态周期失效信号） |
| 容量 | 单票实际成交 < 目标量 50% | 该票次日容量标记减半 |

**仓位纪律**：单票目标金额 = 总资金 × 1/8 与单票容量（14:45 成交额×5%）取小；
总仓位 100%（门控关闭日 0%，持仓照常管理）。
顺延占用日：存在顺延未出场旧仓时，新开仓减至 7 只（或单票目标金额降至 1/9），总持仓不超过 8 只。

## 六、对账与记录（实盘 vs 回测）

每笔字段：`date, code, sig, 日内跌幅, pull_hi（尾盘距日内高点回撤）, 目标金额, 成交量, 成交价, 滑点bps,
出场日期, 出场方式, 出场价, 收益率`。

**对账表（每周）**：实盘日均净 bps vs 回测修正口径 −94.3（2026-10-05 重放；策略重新
通过校验前不进入实盘，本模板待复检后启用）；滑点均值 vs IMPACT 假设；出场方式分布
vs 回测分布（占 2312 笔）：次日卖 21.8% + 次日卖(日线回退) 62.8%、止损合计 10.7%
（含日线回退开盘止损）、顺延后卖 3.3%、T+3 收盘强平 0.9%、末价保守入账 0.5%。
**容差**：日均净差 >80bps 或滑点差 >30bps 持续两周 → 触发 §八校准。

## 七、数据依赖与故障预案

| 依赖 | 来源 | 故障降级 |
|---|---|---|
| 池成分 | iFinD data_pool | 用最近可得日池（标注滞后）；连续缺 2 日停新仓 |
| 实时行情（14:45 截面） | iFinD/东财 | 备用源；双源皆失 → 当日不开新仓（持仓照常） |
| 门控数据（涨停家数） | sentiment 日更 | 用最后可得状态；缺 3 日以上按"关闭"处理 |
| 昨收/20 日涨幅 | 本地日线仓 | 盘前预计算缓存；缺失票直接剔除 |
| 涨停幅判定 | 板块代码规则 | 静态规则，无依赖 |

**原则**：任何数据缺失优先保出场执行（持仓管理不依赖当日数据质量），牺牲开仓。

## 八、首月实盘校准计划（上线必经）

- 第 1-2 周：1/4 资金试运行，逐笔记录滑点；验证滑点分布（均值/P95）与容量假设；
- 第 3-4 周：半仓；滑点均值 ≤0.3% 且对账差 <50bps → 满仓；
- 校准动作：IMPACT 每周回归校准；容量表按实测更新；
- **退出条件**：首月实盘日均净为负、或显著低于重放复检后的回测基准 → 停策复检信号链路
  （v1.1-prod 注：修正口径回测为负，策略未通过校验，本节在重新通过校验前不适用）。

## 十、已知边界（如实声明）

1. p1445 全成交假设：5% 参与率内可信度高，超出未测——§八校准闭环；
2. G2 阈值样本内定义；深跌反包链有生态周期（监管/游资行为）——§五熔断即为此设计；
3. 未建模：盘中临时停牌（按停牌顺延处理）、除权日跳变（实盘需对除权票人工核对昨收）；
4. 回测中约六成笔走日线回退路径（池外票，次日不在池内无分钟行）：该路径自 2026-10-05
   起已按完整状态机执行日线近似——开盘价近似 9:35 止损检查（开盘价与 9:35 实际价存在
   残差，未量化）、收盘价对照涨跌停阈值、非涨跌停按收盘×(1−0.1%) 记卖出。实盘有全市场
   行情，可按分钟价精确执行，回测为近似口径；停牌复牌日无昨收参照时涨跌停判定退化为
   直接按复牌日收盘入账（占比极小）。
5. **日线对齐方向错误（2026-10-05 根因发现，已修复）**：E45-E47 旧管线把「昨收」对齐成
   T+1 收盘（前视）、把出场回退收盘对齐成 T−n 收盘，与执行入口 `select_1445.py`
   （昨收=close(T−1)）不一致；旧版 E47/E49 的 +205/+203.7bps 及 E42-E46 证据链数字均
   属该前视口径，**不可作为生产依据**。修正对齐后本策略三个分年净累计全负，未通过
   生产前校验（见文首状态与 `reports/exp47_report.md`）。E46/E48/E49 的相对结论是否
   在修正对齐后成立，需重放后再审。
6. ST 剔除为最新证券简称口径（`tradable_filter`），历史时点 ST 状态不可考；mom20 缺失的
   次新股（无 20 日历史）自 2026-10-05 起直接剔除（回测与入口同步）。
